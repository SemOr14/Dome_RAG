# Разбор и импорт Kupol.zip — 26.10.2026

Источник: наработки второго участника, архив Kupol.zip (160 591 465 байт). Авторство аккаунта по архиву не устанавливалось. Проект импортирован как приложение `agent/`.

## Что перенесено

151 файл приложения, 36 файлов сохранённых прогонов, один PDF регламента. 21 файл документации/знаний/исторических данных совпал с общей базой после нормализации концов строк и используется из корня репозитория. Исходный README вложенного Dome_RAG заменён общим индексом.

Вложенная история Git, окружение Python, кэши, egg-info и файл ключей не импортированы. Исходный ZIP остаётся локальным источником; его SHA-256, соответствие исходных путей новым и контрольные суммы файлов записаны в [manifest](kupol-2026-10-26.manifest.json).

## Существенные границы

1. Контур `dome/` работает с узлами настоящего WebSocket API. Старый `adapter/real.py` для внутренней плоской модели пока незавершён; наличие панели не означает готовое подключение панели к реальному Куполу.
2. Архивный `BENCHMARK.md` сообщает о 120 прогонах с mock-LLM. Эти цифры сохранены как результат автора и не означают независимую проверку живого Купола.
3. В документах/промптах встречается требование DeepSeek V4 Flash, тогда как `dome.yaml` и материалы API используют `deepseek-chat`. Перед боевым запуском команда должна выбрать модель по актуальным условиям организаторов.
4. В коде нет самостоятельной общей БД/API хранения полного потока. Текущий журнал агента хранит выбранные наблюдения; для требования «весь вход/выход» нужны перехват сетевых сообщений и доставка событий в новый сервис.
5. RAG-материалы теперь общие в корне: при запуске из `agent/` задать `DOME_RAG_DIR=..` (уже добавлено в пример окружения). Дубли данных повторно не создавались.

## Разделение дальнейшей работы

SemOr14 ведёт БД/API (`work/data-api`). Разработчик агентной системы ведёт приложение (`work/agent-system`). Формат передачи событий фиксируется в `contracts/`; изменение чужого компонента согласуется при слиянии. Подробнее: [порядок разработки](../DEVELOPMENT.md).

Проверки импорта и результаты выполнения тестов записываются после локального запуска. Управляющие команды в настоящий Купол при импорте не отправлялись.

## Проверка импорта

142 теста соревновательного контура `tests/test_dome_*.py` прошли за 22,36 с. RAG-тесты использовали общие knowledge/ и Logs/. Полный бенчмарк, Streamlit-панель и реальный Купол при этом не проверялись.
