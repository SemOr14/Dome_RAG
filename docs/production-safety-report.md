## Запуск и настройка возможностей

```bash
python -m pip install -r integration/requirements.txt
python run_panel.py
```

Открыть `http://127.0.0.1:8080/ui/`. По умолчанию competition/history, рекомендательный ИИ,
алгоритмы включены; подключение выключено. Полный справочник — [integration/README.md](../integration/README.md).

Для разрешённого API организаторов явно задать `DOME_API_SCOPE=full`; живую отправку отдельно
разрешает `DOME_ALLOW_CONTROL=1`, а `AGENT_DRY_RUN=1` имеет приоритет. Прямое ручное управление —
только `DEPLOYMENT_PROFILE=service` вне смены. Профиль из UI не переключается.
Отсутствие ответа на единственное уточнение о «только API логов» не трактовалось как выдача живого доступа.

Capabilities строятся из актуального каталога и свежего подключения, неизвестные выключены.
Upload принтера дополнительно требует SHA-256 файла в `PRODUCTION_APPROVED_SHA256`.
Локальная аналитика и история доступны без live API, но не доказывают текущее физическое состояние.
Загрузка ЧПУ, пауза/отмена станков, произвольный G-code и запрос полного refresh телеметрии
не выдумывались: их нет в точном API для агента. Телеметрия приходит push, 10–15-секундный надзор
использует уже полученные кадры. Общий лимит запросов и приоритет safety реализованы одним клиентом.

## Важные ограничения аппаратной интеграции

- Поддержанные управляющие действия реализованы, но реальные станки не подключались. Это
  частичная аппаратная интеграция, проверенная на тестовых ответах/эмуляторе.
- Критические нагрузки и линия 7 сохраняются. При неизвестной длительности продувки/остаточных
  парах линии 1/5 сохраняются; результат жёлтой — partial, с вызовом человека. Фактическую схему
  и дополнительные зависимости задают актуальная телеметрия и CRITICAL_LINE_MAP.
- Полное завершение дерева обеспечивается запуском через launcher. Прямой uvicorn красную
  отклоняет; внешнюю политику restart=always использовать нельзя. Пример systemd приложен.
- Существующая модель `deepseek-v4-flash` не подменена. Её наличие в текущем разрешённом списке
  организаторов ещё нужно сверить без предположений; другой облачный провайдер не добавлялся.
- API списка файлов может не возвращать хеш содержимого: локальная идентичность upload записана,
  побайтовое равенство удалённого файла без серверного хеша не объявляется подтверждённым.
