# Предыдущий прототип агента

Снимок локальной папки kupol_agent на 26.10.2026. Сохранён для переноса контекста; основной разрабатываемый агент команды находится в agent/. Эти две реализации автоматически не объединялись.

Ключи и .env не перенесены. Записи старых запусков и снимок состояния сохранены отдельно в artifacts/legacy-agent-runs; это архив, его состояние не следует подставлять в новый запуск. Во время прежнего запуска в логах наблюдались таймауты подключения к серверу. Этот прототип при переносе не запускался.
