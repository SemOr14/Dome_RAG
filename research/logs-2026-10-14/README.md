# Анализ журналов Купола за 14 октября 2026 года

Эта папка содержит исходные исследовательские материалы и воспроизводимые результаты, построенные по трём локальным файлам `Logs/2026-10-14`: `telemetry.jsonl`, `events.jsonl` и `logbook.jsonl`.

## Результаты

- `Граф_знаний_по_логам.md` — краткое описание графа и примеры доказуемых связей.
- `Граф_знаний_по_логам.json` — полный граф с образцами свидетельств.
- `Граф_знаний_по_логам.graphml` — тот же граф для редакторов графов.
- `Словарь_данных_по_логам.md` и `.json` — наблюдавшиеся пути полей, JSON-типы, примеры и статистика.
- `Анализ_исторических_журналов.json` — инвентаризация локальных записей.

## Метод и ограничения

Граф и словарь используют только локальные журналы. Для каждого свидетельства сохраняются имя файла и номер строки. Строки времени в источниках не имеют часового пояса, поэтому при анализе ему не назначали часовой пояс. Числовые min/max — только наблюдавшиеся границы, не допустимые диапазоны API. Текст участника или агента считается записью его сообщения, а не независимым подтверждением факта.

Каталог API, ответы справочного диалога и снимки состояния — отдельные материалы исследования и не смешиваются с данными журналов. Они не заменяют актуальный `describe_nodes` и не доказывают текущие права управления.

## Повторный запуск

Из корня репозитория:

```powershell
python research/logs-2026-10-14/граф_и_типы_из_логов.py
python research/logs-2026-10-14/анализ_материалов.py
```

Первый скрипт читает только файлы из `Logs/2026-10-14` и обновляет граф и словарь. Второй строит каталог и инвентаризацию по документации и журналам. Скрипты не подключаются к серверу и не отправляют управляющих команд.

Снимки и справочные ответы в этой папке — датированные результаты прежнего исследования; они могут устареть и не должны использоваться как актуальное состояние купола.
