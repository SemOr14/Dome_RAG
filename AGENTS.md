# Правила работы в общем проекте

- SemOr14 ведёт БД/API в `work/data-api`, код в `services/data_api/`.
- Агентная система ведётся отдельно в `work/agent-system`, код в `agent/`.
- Не менять чужой компонент для удобства собственной реализации. Интегрироваться через `contracts/`.
- Изменения форматов входа/выхода сначала фиксировать в общих контрактах и согласовывать при слиянии.
- Сохранять всю телеметрию, события и логи с исходными типами и неизвестными полями. Секретные значения скрывать.
- Исторические данные, симулятор и живые данные различать по источнику и run_id.
- Не запускать живое управление Куполом при проверках импорта и БД.
- Не импортировать вложенную историю Git, окружения Python, кэши или файлы ключей.
