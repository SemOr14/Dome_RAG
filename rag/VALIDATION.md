# Проверка сборки 0.1.0

Дата: 26 октября 2026, Windows, Python 3.13. Проверялась именно эта локальная реализация.

## Поиск

Построены 56 согласованных записей (32 FAQ + 24 ситуации) и 670 справочных фрагментов. Для основной базы вычислены локальные векторы размерности 384, 256 текстовых сегментов. Модель ONNX работает на CPU, 4 потока. Веса находятся в локальном `models/`, в Git не включены.

Гибридный поиск использует точные технические имена, BM25, смысловые векторы и объединение рангов. Наборы проверки:

| Набор | Вопросов с ожидаемыми ID | Нужный материал среди первых пяти | MRR |
|---|---:|---:|---:|
| Проектные вопросы | 63 | 63/63 | 0,966 |
| Перефразировки | 44 | 44/44 | 0,880 |

27 октября база пересобрана: добавлены логи 12–18.10.2026 (WhiteDots/Dome_RAG, 5e1ec48) и 29 исторических ситуаций S25–S53 по ним, S08 стала историческим эпизодом, S54–S56 — документированные ситуации. Всего 88 согласованных записей (32 FAQ + 56 ситуаций), 539 векторных сегментов. В наборы добавлены 32 проектных вопроса по заголовкам новых ситуаций и 24 перефразировки словами Оператора; до этого было 31 и 20 (MRR 0,952 и 0,925). Подробности — `evaluation/hybrid_report.json`.

В исходных 34 проектных случаях три не имеют ожидаемого документа: запрос ключей/подмены инструкций, текущей температуры без данных и посторонний вопрос. Их нельзя включать в знаменатель retrieval Hit@5. Часть отрицательных проверок реализована в unittest.

Проектные вопросы преимущественно повторяют заголовки; перефразировки — отдельный небольшой набор, использованный при отладке. Это регрессионные проверки, не независимый закрытый тест. Процент не доказывает общую точность диагностики и не является вероятностью истинности ответа.

## Локальные тесты

Проверяются: пять этапов ответа, проверяемые ссылки, конфликты, отделение истории от текущих данных, бюджет контекста, будущие метки времени, отсутствие ключей, отказ на подмену инструкций, изменение базы после индексации, фильтрация несогласованных источников, обработка ошибок семантики, DeepSeek-протокол и несуществующие цитаты, отсутствие переноса auth при redirect, локальный HTTP API и запрет облачных вызовов по умолчанию.

Последний полный запуск и фактическое число тестов фиксируются в `evaluation/build_validation.json`.

## Реальный DeepSeek

С пользовательским ключом проверен запрос о `webhook COMPLETED` при продолжающейся печати. Модель `deepseek-flash`, thinking disabled. Получен JSON с диагностическим предложением и допустимыми ссылками на S01/C10 и исходные документы. Расход успешного вызова: 2732 входных + 505 выходных = 3237 токенов.

Проверочный ответ сохранён в `evaluation/live_deepseek_smoke.json`. Ключа в нём нет. Проверены схема и допустимость цитат; корректность любого будущего рассуждения этим не гарантируется. Облачная сеть/бюджет могут стать недоступны, тогда возвращается локальный ответ с явной пометкой.
