# Архив результатов симулятора

Шесть каталогов из Kupol.zip, 36 исходных файлов: 25–26 октября 2026 года. Это результаты разработки участника на симуляторе, а не историческая телеметрия реального Купола.

`telemetry.jsonl` — сгенерированная телеметрия, `journal.*` — решения/события, `sim_events.jsonl` и `ground_truth.jsonl` — разметка симулятора; `summary.json`, `report.md`, `meta.json` — сохранённые метрики и описание запуска. Состав различается между прогонами: отсутствие файла не заполнялось искусственно.

Исходные байты и названия сохранены; SHA-256 каждого файла находится в `docs/imports/kupol-2026-10-26.manifest.json`. Новые прогоны приложения по умолчанию пишутся в игнорируемый `agent/logs/`.
